# Scenario 2_Campus Local Marketplace
# Adele Alsaed

A responsive Single Page Application (SPA) built for university students to buy, and sell items securely and efficiently.

## How to Run the App
1. Clone or download this project repository to your local machine.
2. Open the project folder in **Visual Studio Code**.
3. **Recommended Method**: Open `index.html` using the **Live Server** extension in VS Code for an optimal local development experience.
4. **Alternative Method**: Double-click the `index.html` file directly in your computer's file explorer to open it in any modern web browser (Chrome, Firefox, Edge, Safari).
